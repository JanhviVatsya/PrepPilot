# PrepPilot

**Prepare with purpose.**

PrepPilot is a personalized career preparation platform designed to help aspiring software engineers and working professionals plan career transitions, strengthen technical skills, practice coding problems, and prepare for interviews through structured, goal-oriented learning.

The goal is to bring career planning, technical preparation, project development, and progress tracking into one place.

## 🎯 Vision

Most preparation journeys lack a clear connection between a person's current skills, career goals, and daily learning activities.

PrepPilot aims to bridge that gap by helping users understand where they are, decide where they want to go, and build a practical preparation strategy around their goals, experience, and available time.

## ✨ Planned Features

- **Career Profile** — Define current experience, technical skills, career goals, and learning preferences.
- **AI Career Mentor** — A guided conversation to clarify goals, identify skill gaps, and explore suitable career paths.
- **Personalized Learning Plan** — Turn career objectives into structured learning milestones and actionable daily tasks.
- **Coding Practice & Revision** — Track coding practice and organize topics for revision.
- **Project Roadmap** — Plan hands-on projects to develop practical engineering skills.
- **Analytics & Progress Tracking** — Understand learning progress and identify areas that need more attention.
- **Editable Career Goals** — Adapt the preparation strategy as skills, interests, and circumstances evolve.

*These are product goals; features will be marked as implemented as development progresses.*

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/JanhviVatsya/PrepPilot.git
cd preppilot
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal to view the application.

### Available Scripts

```bash
npm run dev       # Start the development server
npm run build     # Build the production frontend
npm run lint      # Run ESLint
npm run preview   # Preview the production build
```
